# Healthcare Patient Analytics Dashboard

## Project Overview
This project presents a Healthcare Patient Analytics Dashboard built using Microsoft Excel.

The dashboard provides insights into patient demographics, health conditions, and hospital trends.

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Data Visualization

## Key KPIs
- Total Patients
- Average BMI
- Total Cities
- Diabetes Patients

## Dashboard Features
- Gender Distribution
- City Wise Patient Analysis
- Chronic Disease Distribution
- BMI Category Analysis
- Insurance Provider Distribution
- Patient Registration Trend

## Dataset Fields
- Patient_ID
- Gender
- Age
- City
- BMI
- Chronic Condition
- Insurance Provider
- Registration Date

## Insights
- Majority of patients fall in the Adult age group.
- Hypertension and Diabetes are common chronic conditions.
- Patient registrations increased in recent years.
